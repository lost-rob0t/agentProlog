* Historical packaging blocker (resolved)

The original blocker was absence of =prolog-rlm.packages.${system}.default=. That output is present in the pinned dependency now consumed by =flake.nix=. Preserve the ownership boundary: do not copy the generic runtime downstream. Historical Bubble Tea plans below do not describe the implemented canonical Node terminal client.

5. implement the Bubble Tea renderer as a client of the same headless workflow.
